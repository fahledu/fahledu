### Olá, eu sou o fahledu 👋

Desenvolvo ferramentas **pequenas** para resolver problemas do dia a dia.

Sou entusiasta da programação e gosto de usar código para facilitar a minha rotina. Os apps
que mantenho nasceram de necessidades de casa: escrever, cuidar das finanças, treinar e
dividir despesas. Hoje todos usam a mesma conta, em [fahledu.com.br](https://fahledu.com.br).
